# Penablox Recode

## Соглашения

- **Не используй dot-syntax ни для чего, кроме API модулей** (`rage`, `aa`, `entity`, `ui`) — движок резолвит их через метатаблицу, а не как обычные Lua-библиотеки.
- Триплеты `set_*` / `get_*` / `override_*`:
  - `set_*` — пишет в конфиг;
  - `override_*` — форсит значение в рантайме;
  - `get_*` — читает текущее эффективное значение.
- `is_*` — булев шорткат для `get_*`.
- Углы хранятся в **радианах**; `*_deg` возвращают градусы, **но не нормализованы** к ±180 (применяй `% 360` сам).
- `pcall` **не отловит стаб-геттеры** — они молча возвращают `nil`.

---

## Глобальные утилиты

- `json` существует, но **пуст** — используй `HttpService:JSONEncode` / `:JSONDecode`.
- Доступны: `tick()`, `time()`, `wait(n)`, `getgenv()`, `getrenv()`, `getfenv(0)`, `vector(x,y,z)`, `color(r,g,b,a)` (нормализует в 0–1), `notify(msg)`, `bit.band`, `bit32.band`, `utf8.char`.
